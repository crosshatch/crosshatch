# Browser Integration

Import browser-specific APIs from `crosshatch/Browser`. The browser layer owns
the facade connection, link state, proposal bridge, and widget launcher used by
browser applications.

## React

`ChxAtoms` exposes the facade as Effect atoms. `open` launches the link widget
while the session is challenged and the activity widget once it is linked.

```tsx
"use client"

import { useAtomSet } from "@effect/atom-react"
import { ChxAtoms } from "crosshatch/Browser"

export const ConnectButton = () => {
  const open = useAtomSet(ChxAtoms.open)

  return <button onClick={() => open()}>Connect</button>
}
```

The exported atoms are:

- `ChxAtoms.state`: the current `Challenged`, `Linked`, or `Rescinded` session.
- `ChxAtoms.isLinked`: whether the facade is linked.
- `ChxAtoms.open`: open the widget appropriate for the current state.
- `ChxAtoms.propose`: send a payment proposal to the facade.
- `ChxAtoms.rescind`: rescind the current link.

Opening a rescinded session is a no-op. A challenged session defaults to an
allowance of 10 per week. Provide the `Allowance` service to the atom runtime to
override that value.

## Managed Runtime

Outside React, run browser effects with `ChxBrowserRuntime`. It shares the same
memo map and `ChxBrowserServices.layer` as `ChxAtoms.runtime`, so browser
services are initialized consistently.

```ts
import { Payload, Required } from "crosshatch"
import { ChxBrowserRuntime } from "crosshatch/Browser"
import { Effect } from "effect"

declare const required: Required.Required

Payload.make({ required }).pipe(
  Effect.tap(({ payload }) => Effect.log(payload)),
  ChxBrowserRuntime.runFork,
)
```

The current names replace the earlier `BrowserServices`, `CurrentFacadeState`,
and standalone `openAtom`/`stateAtom` exports. Widgets such as `ActivityWidget`,
`LinkWidget`, and `PrerequisitesWidget` are now exported directly from the
Browser subpath.

See [Widget](/widget) to define and launch your own hosted UI.
