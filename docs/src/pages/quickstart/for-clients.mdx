# Client Quickstart

Crosshatch lets clients call paid x402 services through normal HTTP clients.
When a service returns `402 Payment Required`, Crosshatch creates the payment
payload and retries the request with the payment attached.

## Stablecoin Setup

To pay for x402 resources, your client needs a mnemonic from which funded
signers can be derived.

The mnemonic is the secret from which Crosshatch derives signing capability
across supported networks. Any chain-specific signer used to authorize a payment
ultimately comes from this phrase, so keep it private and make sure at least one
derived signer has the stablecoin required by the resource you want to fetch.

## Call a Paid AI Model

Provide `ChxHttp.layerClient` with a `Payer` layer, then use the client
normally. For OpenAI-compatible x402 services like Blockrun, this works directly
with Effect AI.

```ts
import { OpenAiClient, OpenAiLanguageModel } from "@effect/ai-openai-compat"
import { Payer, ChxHttp } from "crosshatch"
import { Console, Effect, Layer } from "effect"
import { LanguageModel } from "effect/unstable/ai"

declare const layerPayerLocal: Layer.Layer<Payer.Payer>

const layerLanguageModelBlockrun = OpenAiLanguageModel.layer({
  model: "deepseek/deepseek-chat",
}).pipe(
  Layer.provide(OpenAiClient.layer({ apiUrl: "https://blockrun.ai/api/v1" })),
)

LanguageModel.generateText({
  prompt: "Hello from Crosshatch.",
}).pipe(
  Effect.tap(({ text }) => Console.log(text)),
  Effect.provide(
    layerLanguageModelBlockrun.pipe(
      Layer.provide(ChxHttp.layerClient.pipe(Layer.provide(layerPayerLocal))),
    ),
  ),
  Effect.runFork,
)
```

## Fetch a Paid Resource

The same layer also works with ordinary Effect HTTP requests. If the first
response is `402`, Crosshatch reads the payment requirement, asks the `Payer`
service for a payload, and retries once with the payment header attached.

```ts
import { Payer, ChxHttp } from "crosshatch"
import { Effect, Layer } from "effect"
import { HttpClient, HttpClientRequest } from "effect/unstable/http"

declare const layerPayerLocal: Layer.Layer<Payer.Payer>

const program = Effect.gen(function* () {
  const client = yield* HttpClient.HttpClient
  const response = yield* HttpClientRequest.get(
    "https://example.com/paid",
  ).pipe(client.execute)
  return yield* response.text
}).pipe(
  Effect.provide(ChxHttp.layerClient.pipe(Layer.provide(layerPayerLocal))),
)
```

`layerPayerLocal` wires the payer to supported assets and signers. In Node.js,
the built-in services load a named mnemonic encrypted at rest, with its
encryption key kept in the operating system keychain. This example uses the
`default` mnemonic and includes known USD assets, EIP-3009, Permit2, and
optional Solana support:

```ts
import { NodeServices } from "@effect/platform-node"
import { Accept, MnemonicStore, Payer } from "crosshatch"
import * as ChxNodeServices from "crosshatch/ChxNodeServices"
import * as Known from "crosshatch/Known"
import { UnifiedSchemes } from "crosshatch/Unified"
import { Config, Layer } from "effect"

export const layerPayerLocal = Payer.layerLocal({
  accept: Accept.first(Known),
  schemes: UnifiedSchemes.layer({
    solana: {
      rpc: Config.string("SOLANA_RPC_URL").pipe(Config.withDefault(undefined)),
    },
  }).pipe(
    Layer.provide(
      MnemonicStore.layerMnemonicFromName().pipe(
        Layer.provide(ChxNodeServices.layer),
      ),
    ),
  ),
}).pipe(Layer.provideMerge(NodeServices.layer))
```

Create the default mnemonic with `pnpm crosshatch mnemonic add`. Pass a name to
both the command and `MnemonicStore.layerMnemonicFromName(name)` to use another
account. Set `SOLANA_RPC_URL` to enable Solana payments. See [Payer](/payer) for
custom asset, policy, and scheme composition.

## Delegate Payment Creation

When another agent should handle approval and signing, delegate payment creation
through a `Bridge`.

```ts
import { Bridge, Required } from "crosshatch"
import { Effect } from "effect"

declare const required: Required.Required

const program = Effect.gen(function* () {
  const { payload } = yield* Bridge.propose({ required }) // [!code focus]
})
```
