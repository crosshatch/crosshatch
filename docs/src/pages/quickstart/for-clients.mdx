# Client Quickstart

Use this guide when your application needs to access paid x402 resources.

Crosshatch helps clients read payment requirements, create payment payloads, and retry requests with the payment
attached.

## Stablecoin Setup

> This step is only relevant if you do not already have a seed phrase and/or stablecoin deposited in one of the derived
> chain-specific signers.

The following command will create a Crosshatch user profile (signing capability) and help you (optional) onramp some USD
Coin on Base (the primary network of the initial x402 build-out).

```sh
crosshatch profile add
```

> Your mnemonics are encrypted with a per-mnemonic X25519 private key, stored in your system keychain via
> [keyring-node](https://github.com/Brooooooklyn/keyring-node).

If you already have a mnemonic with some corresponding funds, you can set it up like so.

```sh
crosshatch profile add --mnemonic <mnemonic>
```

## For Future Reference

You can access the decrypted phrase using the `mnemonic show` subcommand.

```sh
crosshatch profile reveal-mnemonic
```

## Fetch a Paid Resource

`Headless.layerConfig` provides an `HttpClient` that intercepts 402 replies, signs a payment with your seed phrase, and
retries the request with the payment attached.

```ts
import { Mnemonic } from "crosshatch"
import * as Headless from "crosshatch/Headless"
import * as KnownAsset from "crosshatch/KnownAsset"
import { Effect } from "effect"
import { HttpClient, HttpClientRequest } from "effect/unstable/http"

const program = Effect.gen(function* () {
  const client = yield* HttpClient.HttpClient
  const response = yield* HttpClientRequest.post("https://blockrun.ai/api/v1/chat/completions").pipe(
    HttpClientRequest.bodyJsonUnsafe({
      model: "openai/gpt-5-nano",
      messages: [{ role: "user", content: "Hello Crosshatch." }],
    }),
    client.execute,
  )
  return yield* response.json
}).pipe(Effect.provide(Headless.layerConfig(Mnemonic.config("SEED_PHRASE"), KnownAsset)))
```

Outside of Effect, `Headless.makeFetch` wraps the platform `fetch` with the same 402 handling, for handing to code that
expects a plain `fetch`.

```ts
const runtime = await Effect.runPromise(Headless.fromMnemonicConfig(Mnemonic.config("SEED_PHRASE"), KnownAsset))
const fetch = Headless.makeFetch(runtime)
const response = await fetch("https://api.example.com/paid-resource")
```

## Paid AI Providers

`@crosshatch/ai` exposes x402-paywalled AI providers as Effect `LanguageModel`s, so text generation, streaming, tool
calling, and structured output all work through the standard Effect AI API. `Headless.layerConfig` supplies the paying
fetch.

```ts
import { BlockRun } from "@crosshatch/ai"
import { Mnemonic } from "crosshatch"
import * as Headless from "crosshatch/Headless"
import * as KnownAsset from "crosshatch/KnownAsset"
import { Effect } from "effect"
import { LanguageModel } from "effect/unstable/ai"

const program = LanguageModel.generateText({ prompt: "Hello Crosshatch." }).pipe(
  Effect.provide([
    BlockRun.model({ model: "openai/gpt-5-nano" }),
    Headless.layerConfig(Mnemonic.config("SEED_PHRASE"), KnownAsset),
  ]),
)
```

## Create a Payment Payload

When you need more control, drop down to the raw x402 spec and create a payment payload directly from payment
requirements.

```ts
import { Payload } from "crosshatch"
import { Effect } from "effect"

const program = Effect.gen(function* () {
  const { payload } = yield* Payload.make({ required }) // [!code focus]
})
```
