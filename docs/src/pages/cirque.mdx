# Cirque

Cirque combines the on-ramp and facilitator HTTP APIs. It replaces the former
`crosshatch/Ramp` API and client.

```ts
import { AccountId, Amount } from "crosshatch"
import { CirqueClient } from "crosshatch/Cirque"
import * as ChxStage from "@crosshatch/util/ChxStage"
import { Effect, Layer } from "effect"

const program = Effect.gen(function* () {
  const cirque = yield* CirqueClient.CirqueClient
  return yield* cirque.ramp.onramp({
    payload: {
      provider: "Coinbase",
      amount: yield* Amount.from(25),
      recipient: AccountId.AccountId.make(
        "eip155:8453:0x0000000000000000000000000000000000000000",
      ),
    },
  })
}).pipe(Effect.provide(CirqueClient.layer.pipe(Layer.provide(ChxStage.layer))))
```

The response is `{ url }`. Supported providers are `ApplePay`, `Stripe`, and
`Coinbase`, and the amount must be positive.

`AccountId.AccountId` is Crosshatch's branded CAIP-10 schema. It encodes an
account as `${ChainId}:${Address}`, for example an EVM account as
`eip155:8453:0x...`.

`CirqueClient.layer` uses `https://cirque.sh` for production and staging. A
`dev_*` [Crosshatch stage](/configuration) uses `https://cirque.sh.localhost`.

## Migration

- `RampApi` is now `CirqueApi`.
- `RampClient` is now `CirqueClient.CirqueClient`.
- `CaAccountId.CaAccountId` is now `AccountId.AccountId`.
- `ramp.onramp(...)` is now `cirque.ramp.onramp(...)`.
- The on-ramp response field `onrampUrl` is now `url`.
